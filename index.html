SPML uploader

Privacy PolicyTerms of ServiceThe channel

SPML uploader is a private tool, run on one personal computer, that uploads the creator's own videos to one YouTube channel: Same Problems, Modern Life. It uses YouTube API Services to upload videos, set their title, description and schedule time, set thumbnails, add videos to the channel's playlists, post one pinned comment per video, and read the channel's own view statistics. It has one user: the channel owner. It is not offered to the public and has no other users.

By using this tool you agree to be bound by the YouTube Terms of Service. This tool's use of Google data is also covered by the Google Privacy Policy.

Privacy Policy

Last updated 25 November 2026

Who uses it. Only the owner of the Same Problems, Modern Life channel, signing in with their own Google account.

What it accesses. Through YouTube API Services, with the owner's permission (Google sign-in, OAuth 2.0): the owner's own channel name, to confirm the right channel; the owner's own videos, playlists and comments, to upload and manage them; and the owner's own channel statistics (views, watch time, traffic sources) from YouTube Analytics. It does not access any other user's data, and it does not collect data about viewers.

How it uses it. Only to upload and manage the owner's own videos and to read how they perform. Nothing is sold, shared with third parties, or used for advertising.

Where data is stored. The sign-in token and a local upload log are stored only on the owner's own computer. No server or database is used. Statistics are kept in local notes for up to 30 days, then deleted or summarised.

How to remove access and delete data. Access can be revoked at any time at Google Account security settings (third-party access). Deleting the local token file removes the tool's access on the computer; deleting the local log removes any stored data. Any stored API data is deleted within 7 days of access being revoked.

Google. This tool uses YouTube API Services. See the Google Privacy Policy.

Contact. Through the channel's About page on YouTube: youtube.com/@SameProblemsModernLife/about.
